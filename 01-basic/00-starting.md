### 环境准备

所有的示例，使用纯Javascript + JSDoc编写。

- NodeJS，>= V22
- VSCode，作为集成开发环境
- Git，拉取示例代码

### 下载此书及其示例代码库：

```shell
git clone git@github.com:kree4x-books/kree4js-getting-started.git
```

### 构建工程

切换到工程目录：

```shell
npm i
```

### 有问题？

如有可能，不要手工。

打开你的AI IDE，使用自然语言，指挥它干活。

手工敲命令行，配置环境，实际有点傻。
